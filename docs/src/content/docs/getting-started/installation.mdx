---
title: Install
description: Build or install Docksmith for macOS.
---

Docksmith requires macOS 14 or later. Building from source requires a Swift 6 toolchain. Apple Configurator's separately installed `cfgutil` provides Home Screen editing and app management. Optional Xcode supplies an alternate app inventory and supported app removal through `devicectl`; Xcode is not required for USB detection or Configurator features. Docksmith does not include or redistribute Apple software.

From the repository root:

```sh
swift build
swift run DocksmithApp
```

The Swift package also provides the `docksmith` read-only CLI. Run `swift run docksmith help` to see its commands. To build a local app bundle, run `swift build -c release && scripts/bundle-app.sh release 0.1.0 1 dist`; the bundle is written to `dist/Docksmith.app`. For a packaged release, use the release notes to verify the ZIP archive and install the app in Applications. Current release artifacts are unsigned and unnotarized.

If the app cannot find `cfgutil`, choose its executable in the setup screen or Connection view. The CLI accepts a path argument:

```sh
swift run docksmith devices --cfgutil "/path/to/cfgutil"
```

The path must point to an executable `cfgutil` binary. See [device connection](../../guides/connect-a-device/) before managing a device, or [`devices` and `probe`](../../reference/cli/) for read-only inspection.
