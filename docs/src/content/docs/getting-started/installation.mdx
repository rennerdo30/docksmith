---
title: Install
description: Build Docksmith's current macOS command-line probe.
---

Docksmith currently ships as a Swift package. Building from source requires macOS 14 or later and a Swift 6 toolchain. The probe also requires Apple's `cfgutil`, installed separately with Apple Configurator. Docksmith does not include or redistribute Apple software.

From the repository root:

```sh
swift build
swift run docksmith help
```

If a release provides a CLI archive, use its accompanying release notes for installation and verification. Release assets may be unsigned or unnotarized; check the release description before opening a downloaded executable.

If `cfgutil` cannot be found, supply the path to your installation:

```sh
swift run docksmith devices --cfgutil "/path/to/cfgutil"
```

The path must point to an executable `cfgutil` binary. Run [`devices` and `probe`](../../reference/cli/) after connecting and trusting a device.
