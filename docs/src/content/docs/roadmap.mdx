---
title: Roadmap
description: Planned capabilities beyond the read-only CLI.
---

Docksmith's current milestone is a read-only, explicitly selected CLI probe. These ideas are planned and **not implemented**:

- A native macOS interface for exploring supported device capabilities.
- Batch app deletion with a preview and explicit confirmation.
- Home Screen layout editing gated by verified device capabilities.

Those features would change device state and require their own design and validation. The present CLI cannot delete apps or write layouts. Wireless `cfgutil` probing is also unverified.
