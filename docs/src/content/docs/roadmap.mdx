---
title: Roadmap
description: Current limitations and planned improvements.
---

Docksmith now has a native macOS interface for app inventory, confirmed batch removal, and icon and folder layout editing. The read-only CLI remains available for inspection.

Current limits and future work include:

- Widgets and widget positions are outside the Home Screen editor.
- Unsupported layout entries and partial layout reads block Apply until the format is understood.
- Wireless `cfgutil` reads and changes have not been verified. Finder's Wi-Fi setup instructions do not establish Docksmith support.
- Broader device and OS compatibility needs validation. A connected device can report unavailable data or reject a change.
